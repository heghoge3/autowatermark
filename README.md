# Авто-вотермарка

Выбираешь вотермарку и много фото — она накладывается в правый верхний угол. Регулируются прозрачность, размер и отступ. Результат — в папке `watermarked` рядом с фото.

**Скачать:** вкладка Releases → `AutoWatermark.exe` (или Actions → последний запуск → Artifacts). Запускается двойным кликом, установка не нужна.

Из исходников: `pip install pillow && python autowatermark.py`
